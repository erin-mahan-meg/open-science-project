# Simulated Epilepsy Surgery Cohort

This project demonstrates a reproducible research workflow using Python, Git, GitHub, and Quarto. It follows a simulated cohort of patients who underwent epilepsy surgery from initial data inspection through cleaning, descriptive analysis, visualization, and reporting.

All patient records are synthetic. The repository contains no real patient or clinical data, and its results should not be interpreted as clinical evidence.

## Project aims

The project was created to practice:

- generating and documenting synthetic research data
- creating understandable analysis and figure pipelines
- communicating the complete workflow in a Quarto report

## Repository structure

```text
project_folder/
├── data/
│   ├── epilepsy_surgery_data_dictionary.csv
│   └── simulated_epilepsy_surgery_raw.csv
├── scripts/
│   ├── data_generation.py
│   ├── data_description.py
│   ├── data_cleaning.py
│   ├── descriptive_statistics.py
│   └── make_figures.py
├── outputs/                         # Generated when the workflow runs
├── report.qmd
├── README.md
└── .gitignore
```

The raw simulated dataset and its data dictionary are version controlled. The cleaned dataset, tables, figures, and rendered report are generated from code and excluded from version control where specified in `.gitignore`.

## Workflow

The Quarto report runs the analysis in the following order:

1. `data_description.py` inspects the raw dataset and creates a subject-level data-quality report.
2. `data_cleaning.py` removes exact duplicates, standardizes known category inconsistencies, replaces implausible values with missing values, recalculates epilepsy duration, and writes a cleaned CSV.
3. `descriptive_statistics.py` creates an Engel-stratified descriptive table from the cleaned data.
4. `make_figures.py` creates a presurgical modality coverage figure and a figure comparing multimodal concordance with Engel outcome. It also performs the Spearman rank test shown with the concordance figure.
5. `report.qmd` combines the narrative, tables, figures, and statistical result into a self-contained HTML report.


## Software requirements

The analysis requires Python 3, a Python Jupyter kernel, and [Quarto](https://quarto.org/).

Install the required Python packages in your chosen environment:

```bash
python3 -m pip install PyYAML jupyter pandas numpy matplotlib seaborn scipy
```

You can confirm that Quarto can access Jupyter with:

```bash
quarto check jupyter
```

## Reproducing the report

Clone the repository, enter the project directory, and render the report from the project root:

```bash
quarto render report.qmd
```

For a live preview while editing:

```bash
quarto preview report.qmd
```

Rendering the report runs the inspection, cleaning, descriptive-statistics, and figure code in the required order. It produces `report.html` together with the cleaned data and tabular outputs generated by the scripts.

## Data notes

The dataset intentionally includes a small number of quality issues so that the cleaning workflow can be demonstrated. These include exact duplicate records, inconsistent capitalization, missing values, an implausible chronology, and an extreme seizure-frequency value.

Engel outcome is represented by classes I–IV, with lower classes indicating better post-surgical seizure outcomes. The project uses these ordered classes for descriptive summaries and an exploratory Spearman rank correlation. Because the data are simulated, the observed associations reflect the data-generation process and are not estimates of real-world clinical effects.
